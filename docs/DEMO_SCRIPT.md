# ScamLens demo flow

1. Open the landing page and show the promise: “See the signal. Stop the scam.”
2. Create an account or sign in.
3. Start the baseline. Complete all eight balanced categories; point out that there is no per-question correctness or coaching reveal.
4. Review the completed baseline score and strongest/focus categories.
5. Start adaptive practice. Inspect a safe simulated message and choose an answer and any signals noticed.
6. Submit. Show the deterministic grade first, then the concise Gemini coaching note when available. The displayed `.example` address is not clickable.
7. Complete additional practice and point out the latest-outcome category focus and difficulty changes.
8. Take the final assessment. It uses eight scenario IDs that were not in the baseline and withholds item-level grading until completion.
9. Review baseline score, final score, percentage-point change, and category performance.
10. Open history and show private response records and reflection notes.

This is a controlled training simulator. It does not inspect real messages or open, fetch, or crawl URLs.
